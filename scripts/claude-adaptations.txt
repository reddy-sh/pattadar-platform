# Claude Code wording rules for scripts/sync-claude-from-kiro.py.
#
# The sync copies .kiro/{steering,skills,skill-evals} to .claude/{rules,skills,skill-evals},
# drops the steering frontmatter, renames security-review to pattadar-security-review and
# points .kiro/steering/<name>.md paths at .claude/rules/<name>.md. Everything else that must
# read differently in Claude Code is a rule below: the exact text in the .kiro file and the
# exact text Claude Code gets instead (written as is, without the rename). Each kiro text must
# occur exactly once in its file, so when a .kiro edit changes it the sync stops: edit the
# rule to the new .kiro wording and keep the Claude Code meaning. Lines inside a block are
# literal (keep them byte-exact); an empty claude block deletes the kiro text. Add a rule
# only for a real Claude Code difference, with Reddy's agreement (agent-skill-maintenance
# step 4); the .claude/skills/README.md header lists the categories.
#
#   @@@ file <path under .kiro>
#   @@@ kiro
#   <text>
#   @@@ claude
#   <text>
#   @@@ end
