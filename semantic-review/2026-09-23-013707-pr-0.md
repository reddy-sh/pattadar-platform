# Exact-file gateway streaming with native media playback

This change replaces whole-file W360 audio/video blobs with a Bearer-minted, exact-node/version cookie and gateway-proxied HTTP ranges, while retaining the buffered image, HEIC, and thumbnail path. It also adds audio filing, browser-generated video posters, and bounded range reads for live EXIF inspection. Cookie requests reconstruct immutable issuer/subject identity, run the account-access gate, and re-run storage/share authorization for each request. **Watch for:** **confirmed, High** S3 bodies are not deterministically closed on disconnect; **confirmed, High** an interrupted first stream can consume the audit claim without writing an event; **confirmed, Medium** malformed/empty Authorization can downgrade to a stream cookie; and **confirmed, Medium** expired or logged-out sessions have no recovery/revocation path.

**Verdict**: NEEDS_CHANGES

## High-level view

The stream-session POST authorizes the Bearer principal, resolves an immutable version, stores only a token hash with issuer/subject, and sets a host-only, HttpOnly, SameSite=Strict cookie scoped to that node’s content path. Cookie lookup requires the exact URL version. Each GET, HEAD, or range maps the same immutable principal through reviewed legacy bindings, invokes the account block check, and calls `content_identity`; share revocation therefore affects the next request, though an already-open response is authorized once.

The range branch handles one open, closed, or suffix range and emits 206/416 `Content-Range`, `Accept-Ranges`, and bounded `Content-Length`. Ordinary images retain `format=web`/thumbnail HEIC conversion. The new streaming body and audit lifecycle is unsafe on disconnects and post-open database failures.

Audio waits for a click, while every rendered video immediately mints a session and loads a hidden video for its poster; the strip renders every thumbnail. Sessions expire after 15 minutes, but the hook ignores expiry and media load errors, while sign-out clears only Cognito state.

EXIF asks for the first 256 KiB and parses JPEG locally. A legacy/intermediary 200 response is fully buffered, defeating that bound, and HEIC remains display-compatible while the JPEG-only metadata UI reports it as lacking location.

Audio enters the existing photo-row model, but photo-only evidence text and actions remain. Setting audio as cover clears the photo cover even though record-card selection ignores non-photo cover rows.

The new table is additive and startup-locked, so old tasks can coexist and rollback can leave it in place. Its request-path cleanup is unbounded despite its comment.

<details><summary>Details</summary>

## Stream cancellation leaks the opened S3 body

**Severity: High — confirmed.** `_stream_body` closes only when its synchronous iterator is finalized, but Starlette 0.50 returns from an ASGI send disconnect without closing it. A local reproduction against the pinned version raised `ClientDisconnect` with `CLOSED_AFTER_DISCONNECT=False`. The route also opens the body before `claim_first_use`; if that DB operation raises, no response owns it. Repeated disconnects or a DB incident can retain S3 HTTP connections and exhaust the client pool (`services/gateway/src/routes/storage.py:255-264,518-545`).

Make a dedicated response lifecycle close the body in an outer `finally` on success, cancellation, send failure, and setup failure. Add disconnect and claim-failure tests that assert closure before the response returns. The architecture claim that bodies close “on completion or disconnect” is currently false (`docs/architecture.md`).

## First-use claiming can permanently suppress the download audit

**Severity: High — confirmed.** Cookie playback sets `first_used_at` before any chunk is sent, but `record_audit` is a background task that Starlette reaches only after successful streaming. Disconnect or body-read failure skips it; later ranges see the consumed claim and never schedule evidence (`services/gateway/src/routes/storage.py:526-545`, `services/gateway/src/stream_sessions.py:59-72`).

Define the event as authorized access and atomically claim plus enqueue it, or keep retryable `audit_pending/audited_at` state. Cover disconnect, body-read and ingest failure followed by a successful range. The runbook’s “first successful use records” statement currently overstates behavior (`docs/runbooks/scoped-recipient-access.md`).

## Cookie fallback does not require Authorization to be absent

**Severity: Medium — confirmed.** `_content_auth` uses `validate_bearer(..., strict=False)` and falls back on `None`. That validator returns `None` for wrong schemes, empty Bearer values, and—before reading the header—absent/incomplete auth configuration. A malformed three-part JWT is rejected when configured, but not every presented invalid credential fails closed (`services/gateway/src/routes/storage.py:208-229`; `services/gateway/src/auth.py:100-144`).

Fall back only when Authorization is entirely absent; otherwise use strict validation and propagate 401/503/configuration failure. Add valid-Bearer precedence, malformed/empty/wrong-scheme, unavailable-JWKS, and absent-header cookie tests. The current suite replaces `_content_auth`.

## Expiry and sign-out leave native players stranded or still authorized

**Severity: Medium — confirmed.** `useMediaStream` discards `expiresIn`, remains `ready`, and retries only session POST failures. `<video>`/`<audio>` has no `onError`, so delayed play or a seek after 15 minutes gets 401 without returning to retry UI (`apps/web/src/w360/mediaStream.ts:19-55`, `apps/web/src/w360/ui.tsx:254-318`). Sign-out clears local Cognito/OIDC state but cannot clear exact-path HttpOnly cookies, and the gateway has no subject/session revocation; known URLs remain usable until TTL.

Track absolute expiry, remint near expiry/on play, and map media errors to a fresh Bearer session. Add a Bearer-only revoke-all operation keyed by issuer/subject before sign-out, or bind rows to a revocable login session. Account freeze is rechecked through the existing 30-second cache.

## Poster generation scales with the whole gallery and retains decoder state

**Severity: Medium — confirmed.** Every `shown` video renders `VideoThumb`; each immediately creates a session and hidden video, while the selected stage creates another (`apps/web/src/w360/pages/RecordPhotos.tsx:901-928`, `apps/web/src/w360/ui.tsx:267-270`, `apps/web/src/w360/videoPoster.ts:12-54`). After capture, the hidden source, decoder buffers, closures, and base64 JPEG remain until unmount.

Generate selected/near-viewport posters only, cache one per node/version, and share it between stage and strip. Detach after capture/error, prefer `toBlob` with revoked object URLs, and cap concurrency. Test bounded requests and cleanup in a long gallery.

## Metadata compatibility can turn a 256 KiB read into a full download

**Severity: Medium — confirmed.** `fetchFileRange` accepts 206 or 200 and calls `res.blob()`. A legacy gateway or Range-stripping intermediary can therefore buffer the entire object—up to the gateway’s 100 MB limit (`apps/web/src/pages/documents/storage.ts:107-118`, `apps/web/src/w360/photoExif.ts:25-57`).

Validate 206 plus `Content-Range`. For legacy 200, read only the requested count from `response.body`, cancel immediately, and reject unsafe fallback lengths. Test valid 206, bounded/oversized 200, missing body, and malformed range headers.

## JPEG-only EXIF is presented as proof of missing HEIC location

**Severity: Medium — confirmed.** `readExif` accepts JPEG SOI/APP1 only, but `useExif` runs for every photo row. HEIC remains viewable via `format=web`/`thumb`; its raw metadata read returns the empty JPEG result, and `PhotoGeoCheckBlock` says the file “carries no location” (`apps/web/src/w360/exifGeo.ts:105-119`, `apps/web/src/w360/photoExif.ts:25-57`, `apps/web/src/w360/pages/RecordPhotos.tsx:85-139`).

Carry MIME/name into the hook and expose `unsupported` separately from `ready/no GPS`, or add bounded HEIC extraction. Preserve the existing image/thumbnail path and avoid evidence claims for unparsed formats.

## Non-photo rows inherit photo-only evidence and cover behavior

**Severity: Medium — confirmed.** Audio is stored as `media_kind='audio'`, but the panel renders photo location/provenance unconditionally. “Make cover” is also available: the API clears the prior cover and marks audio/video, while card selection filters to `media_kind='photo'`, creating contradictory gallery/card state (`apps/web/src/w360/filePhotos.ts:27-43`, `apps/web/src/w360/pages/RecordPhotos.tsx:944-1064,1108-1121`; `services/api/src/web360.py:2003-2006,8362-8383`).

Render photo evidence and cover only for photos, use media-neutral labels elsewhere, and reject non-photo covers server-side without clearing the old row. Test both API state preservation and audio/video details.

## Extension fallback does not fix the response MIME seen by the player

**Severity: Medium — likely.** The server classifies `.mp4`/`.m4a` as media to support generic MIME, but `StreamingResponse` sends the stored type unchanged under `nosniff`. `application/octet-stream` can get range behavior yet fail browser media selection; tests cover only `video/mp4` (`services/gateway/src/routes/storage.py:174-205,471-545`, `services/gateway/tests/test_media_streaming.py:21-86`).

Map allowlisted generic extensions to conservative media types while retaining sandboxing. Verify generic-MIME MP4/M4A and unsupported-codec errors in Chromium and WebKit.

## Session cleanup is unbounded on the request path

**Severity: Low — confirmed.** `create` describes bounded cleanup but deletes every expired row before inserting, leaving burst cleanup, WAL, and lock cost on stream-session latency (`services/gateway/src/stream_sessions.py:25-43`).

Delete a fixed indexed batch or move retention to a reviewed job. Prove the per-create deletion bound in a database test.

## Tests bypass the security boundary and failure lifecycle

**Severity: Medium — confirmed.** The gateway suite monkeypatches `_content_auth`, `claim_first_use`, and audit. It checks basic ranges, 416, normal closure, image fallback, and cookie attributes, but not immutable identity, account freeze, version mismatch, share revocation, expiry, invalid Bearer precedence, HEAD, disconnect, read failure, or audit deduplication. No web test covers session recovery, poster bounds, audio controls, HEIC state, or bounded 200 fallback.

Add real-boundary gateway tests with fake DB/storage authority, direct ASGI cancellation, and focused browser/hook coverage. Targeted gateway tests and web typecheck pass, but do not falsify these findings.
