What changes

  • 1The name cell holds the shared `.rowopen` button ("Open <name>"). It and a click anywhere on the row open the person's drawer, deep-linked as `?g=<group>&m=<member>`.within authority
  • 2A read-only member drawer built on the shared `Drawer` in look mode (no footer). Its outlined Edit opens the existing PersonDialog, and its kebab is the row's own actions from one pure `memberActions(m)`.within authority
  • 3Details, Family, Share and Activity shown as `KV as="dl"` sections. Every absent value reads "not set", and a parent or spouse is a link that opens that person.within authority
  • 4An owner-scoped `memberDetail` query (D2, blocked until Reddy approves) returns the masked Aadhaar and the kept card's pointers, opened in the shared PaperPreview and scan. Attaching other documents needs `documents.member_id` (D3, not in this delivery).Reddy's decision
  • 5Born uses the shared `ddmmyyyy` (string-only, no Date) in the table and the drawer.within authority
  • 6The members table gets the existing `.scroll-x.edgefade`, and the drawer carries every column a phone cannot.within authority
  • 7Verified shows as a word in a `StatusChip` ("Verified" / "Not verified"), not a titled glyph.within authority
  • 8Use "Documents" instead of "My Drive" in the card copy, and decide whether "Members" stays the tab noun for people in a family group (D5, not in this delivery).Reddy's decision

Already meets the standard

  • Aadhaar shows only the last 4 digits through `formatAadhaarMask`, in tabular figures (Groups.tsx:832).
  • Loading and failed reads use the shared `Loading` and `Failed` (Groups.tsx:698-702).
  • The row kebab is the shared `Menu` and names its subject in `header`, and Remove asks first in a dialog (Groups.tsx:849-854, 881-911).
  • PersonDialog is reused rather than redrawn, behind a lazy import (Groups.tsx:101).

Same rules on every section

  • No filled button inside the drawer. The tab's "Add a person" stays the one filled action.
  • Dates are DD/MM/YYYY: `ddmmyyyy` for a date of birth, `fmtLocal` (date only, local day) for a timestamp. Digits use `tabular-nums`.
  • A missing value reads "not set", never blank or 0.
  • Aadhaar is the last 4 digits only. No 12-digit value reaches the client.
  • One face (Atkinson Hyperlegible, 400/700), composed only from ui.tsx, Drawer.tsx and paper/.
  • Every control has a name. Esc closes, and focus returns to the opener.

Guardrails

  • Identity kept: Bloom tokens, the W360 shell, the Groups list-over-detail macrostructure (Groups.tsx header comment) and the drawer as W360's person surface (RecordPeople.tsx).
  • Needs Reddy: the new `memberDetail` GraphQL contract exposing card pointers (D2); `documents.member_id` and "Attach a document" (services/api main.py schema, plus the Documents vault); showing the card's read-back fields or a blurred card preview (privacy); the "Members" noun and the "My Drive" wording (design.md § App vocabulary).
  • Possible within current authority: 1, 2, 3, 5, 6 and 7 from the existing `members` data. The card half of 4 waits for D2; if refused, the drawer ships without the Documents card row.
